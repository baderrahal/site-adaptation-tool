# Report

Run `pwsh scripts/status.ps1`, then write four short parts in plain English, for Bader:

- **Done**: with the PR number and the proof for each.
- **What remains**: from steps/backlog.md and open tasks.
- **Known bugs**: with file and line, or how to see each one.
- **What comes next**: the next three steps and who does each.

Anything not proven is UNKNOWN. Anything not seen in Revit says so. Do not write it to a file unless asked.
