# Questions

Sources: steps/questions-open.md, steps/questions-for-bader-4nov.md and the "only I know" parts of steps/handover/.

1. Close duplicates, naming the question that stays.
2. Answer from docs, with file and line. An answer with no proof is not an answer.
3. Set a default where the recommended answer is safe to undo. Tag it `assumed` with the date in steps/questions-closed.md, so Bader can overturn it.
4. Keep for Bader only what changes the design, spends money or cannot be undone. At most 15, and the five named first in steps/questions-for-bader-4nov.md lead.
5. Write them in one form, each with its Q id, a title of at most 8 words, the recommended answer first, and what depends on it. Use steps/questions-for-bader.md, replacing the last form.

Never renumber or reuse an id. Report the counts: open before, closed as duplicates, answered from docs, assumed, left for Bader.
