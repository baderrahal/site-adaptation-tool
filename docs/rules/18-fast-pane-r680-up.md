## Fast build FAST-1 of build-1, the pane in 3 stages, 6 to 8 Nov 2026

Bader's order of 6 Nov. Written by Lead from steps/heads-up/build-1.md, the branch task/FAST-1-build-1 at ebb346e and the body of PR 232 for R682 to R685, as docs/rules/ is on the list of FAST-2. A new part, so the two lanes write no rule file in common.

- **R680 The pane in 3 stages.** Input: the state of the 9 steps of the pane and the settings of the project. Output: a docked page with three cards in order, Project data for steps 1 to 3, Build site for 4 to 8, Review and deliver for 9, each with its status, an i icon and one main button, a Settings gear, and Advanced, closed by default, holding the version 1 pane whole. A card whose work is not built says so in plain words. Test: dotnet/SiteAdaptation.Tests/FAST1/R680_StagePaneTests.cs.
- **R681 Stage 1, folder and data check.** Input: the folder a person picks, the latest read folder of the work folder and its data_check.json. Output: Choose project folder writes that folder into the config copy of a new project under the work root only, never into a file a person edits, then runs 2 Read data. The card lists each need with strong, usable, weak or missing and its plain line. Fix items opens the Confirm window of R2-C1. Test: dotnet/SiteAdaptation.Tests/FAST1/R680_StagePaneTests.cs.
- **R682 The rules table of a project.** Input: the config, the rules profile and the work folder of the active project. Output: a window from Settings with each rule of ruleIds, its value, source, status and mark, Confirm or Save by rulesChange, Use the manual template by rulesSetup, Before Build warn or block, all in process by WorkerRunner.Run. It writes only a new project's copy under the work root, never the shipped set, a past job or the repo. Test: dotnet/SiteAdaptation.Tests/FAST1/R682_ProjectRulesTests.cs.
- **R683 One amber line of the rules.** Input: RulesForBuild.Check of the project. Output: one line on the pane while no rules are chosen or a settable rule is not confirmed, none when all are. Test: dotnet/SiteAdaptation.Tests/FAST1/R682_ProjectRulesTests.cs.
- **R684 The manual template in the install.** Input: rules/templates/manual.json. Output: the same file in ShippedSet of the installed add-in, never past-job.json. Test: dotnet/SiteAdaptation.Tests/InstallScriptTests.cs, the shipped list, and dotnet/SiteAdaptation.Tests/FAST1/R682_ProjectRulesTests.cs.
- **R685 Stage 1 sends the parameter sheet.** Input: the parameter sheet of the settings, else of config. Output: the input parameterSheet of the dataCheck request when the file is on disk, none when not. Test: dotnet/SiteAdaptation.Tests/FAST1/R685_SheetInputTests.cs.
