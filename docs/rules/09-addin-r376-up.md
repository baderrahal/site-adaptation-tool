## Round ADDIN rules of Lane B 5a and 5b, written in 5c (J9)

From their rows of docs/design/10-rule-ids.md and what the code does.

- **R370 Install script, manifest, one Common.** Install-SiteAdaptation.ps1 installs per user only, with no admin, into %APPDATA%\Autodesk\Revit\Addins\2024 by the design of docs/design/08-install.md: the manifest and a folder of the add-in that holds its own copy of SiteAdaptation.Common, since Revit loads one copy of an assembly for every add-in, so the add-in resolves its Common from its own folder before any type of it loads. The script runs in PowerShell 7 against a temporary add-ins root in the tests. Tests: InstallScriptTests.cs, AddInTests.cs.
- **R371 The ribbon.** The tab, the panels and the buttons of 7.1 of docs/design/12-ui-spec.md, Bader's ribbon of 28 Oct 2026 in its order, four panels and eleven buttons with their icons. The manifest names the application class, whose resolver comes first. One command per ribbon button, each hands only its number, or its own name for a button with no number, to Buttons.Run, the one entry of a button the ribbon and the test host call. Every colour and font size of a window is written in Theme.xaml only, held by the gate test. Tests: AddInTests.cs, ThemeGateTests.cs.
- **R372 The pane and the document.** The pane of 7.2 of docs/design/07-mock.md is bound to the active document: the Revit side hands each document event to PaneSessions, a worker answer comes on a thread of the pool and is routed to the document that started it, never to the active one. The work folder of a document is named by its file name and the hash of its path in the work root of WorkRoot.cs (06-settings.md, J8). An input file is hashed by its content, a folder by the list of its files. Revit takes VisibleByDefault only the first time a pane is loaded. The settings are saved with the project by R367. Tests: PaneTests.cs, PaneRunStateTests.cs, AddinRunTests.cs, AddinRunAddInTests.cs, RevitRunTests.cs, UiLabelTests.cs, UiShotTests.cs.
- **R382 One transaction per button.** Each button runs as a body of one flow: the steps outside Revit first, the confirm before any write, Apply or Cancel with Cancel the default so Enter changes nothing, a dry run into the dry folder of the run, then one transaction of the real run with its failure preprocessor, the roll back of all of it with the reason on any failure, and the stop. A document is held as saved only by SavedPath.Is. The add-in keeps its own copy of the WarningCollector of the placer (R86). Tests: ButtonFlowTests.cs, AddinRunTests.cs, AddInTests.cs, PaneTests.cs, SetUpSiteAddInTests.cs, SetUpSiteLogicTests.cs.
- **R373 Button 1 on an empty project.** SetUpRun of Common/SetUp decides and the Revit side carries it out, the window known only by ISetUpSiteDialog. The order of its steps: the survey point and the project base point by the position file of addin.position.file, the units by Document.SetUnits, the length of the position file and area, angle and slope by addin.siteUnits, the levels by Level.Elevation on their stated base, the floor types of config with the Ramps type of the slope chosen from rampSlopeChoices of the level profile, its default rampSlopePercent.default, the wall types of addin.wallTypes (J18), and the shared parameters by GUID from the parameter sheet, with the stop and the list on a parameter of a name of another GUID, written through a shared parameter file of the run named by the run id and deleted after. The check points hold the CAD shared point against the Revit point of its internal point in mm at gapDecimals, passing at addin.position.revitCheckPointLimitMm, 0.1 mm by Q142 (W2). The badge says what button 1 would set. A missing key of config or of the rules profile is refused by its name. Tests: SetUpSiteLogicTests.cs, SetUpSiteTests.cs, SetUpSiteAddInTests.cs.
- **R374 Button 1 on an existing site file.** On a model that holds a site already, button 1 shows each sign of what differs and its stops in its dialog with no tick and no save of the position, and a second run that finds nothing different commits nothing. The R17B stand-in of 5b, the parameter names with GUIDs of their own as R212 made them, stops with the parameter sign. Tests: SetUpSiteLogicTests.cs, SetUpSiteTests.cs, SetUpRunHostTests.cs.
- **R383 Element tags in Revit.** A schema name holds letters, digits and underscore only, and each run logs its library and memory line. Button 1 calls one tag step, filled from R368 of 4h in 5c. Tests: SetUpSiteLogicTests.cs.
