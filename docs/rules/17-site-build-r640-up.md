## Round R2 C2 of build-1, Build site, the plan of siteBuild, no Revit call

Bader's order of the round: stage 2 builds from the plot table of stage 1 with no past file. A value with no rule is never guessed. Written by build-1 under Rules for Lead of steps/tasks/R2-C2-build-1.md and entered by Lead, as docs/rules/ is build-2's. R649 to R654 stay free. Each rule is CHOSEN by Code unless its question says otherwise.

- **R640 The siteBuild plan.** Input: a request of the command siteBuild with the plot table of stage 1, the project profile and the config, and the optional inputs positionFile, its format in the comments of SiteCoordinates.cs, rules, read by RulesForBuild of R2-C3, placedFloors, masses and roadEdge, their formats in the comments of FloorsToReplace.cs, MassOverlap.cs and NeighbourhoodCut.cs. Output: build_plan.json and preview.json, and no model is touched. It reads no past file and no override list. Every value of a plot carries a source: computed, rule with its rule id, person entered, default or missing. A value with no rule and no read stays empty with its reason and the plot is marked. A value of source past is never written outside past job mode. Test: dotnet/SiteAdaptation.Tests/SiteBuild/SiteBuildTests.cs, class R640_PlanTests.
- **R641 Numbers from a manual rule text.** Input: the text of a rule of the rules file. Output: a number only in a plain form: M10 "<unit types> always have <n> steps", M13 "Front setback <n> m" with ", <unit type> <n> m" for a unit type of its own, M11 and M12 "FFL + <n> m". The value has source rule, the rule id, and the status of the rule. A text in any other form gives no number and an issue. Q501. Test: dotnet/SiteAdaptation.Tests/SiteBuild/SiteBuildTests.cs, class R641_RuleNumbersTests.
- **R642 Coordinates of an empty model.** Input: the plot outlines of the plot table, coordinates.originRoundM, the optional position file. Output: the centre of the box of the plot outlines, rounded to coordinates.originRoundM. The position file is only a check. The plan gives both and the difference in mm. A box outside the UTM zone is an issue. Test: dotnet/SiteAdaptation.Tests/SiteBuild/SiteBuildTests.cs, class R642_CoordinatesTests.
- **R643 Only a blocking line stops.** Input: the plot table and the rules of a build. Output: a build stops only on a blocking line: the plot table cannot be read, it holds no plot, no plot has an outline, or the rules say block. The line is in plain CAD and Revit words with no brace and no word null. Every other fault is an issue with its plot, and the build goes on. Test: dotnet/SiteAdaptation.Tests/SiteBuild/SiteBuildTests.cs, class R643_BlockingTests.
- **R644 Steps and the 2D preview.** Input: the plan of a build. Output: the steps in the order of the buttons 4 to 8 with the plots ready for each, and one progress line. preview.json holds the closed outline and villa type of each plot with the count of issues, before anything is written. Test: dotnet/SiteAdaptation.Tests/SiteBuild/SiteBuildTests.cs, class R644_StepsTests.
- **R645 Plot outlines in the plot table.** Input: the same reads of the drawing as dataCheck makes. Output: the plot table of stage 1 holds the outline of each plot in metres. A plot without a ring has none and the run says so in an issue, an empty ring is never written. Test: dotnet/SiteAdaptation.Tests/SiteBuild/SiteBuildTests.cs, class R645_PlotOutlinesTests.
- **R646 Overlap on the whole site.** Input: the plot outlines, siteBuild.massOverlapMm, and the rings of the masses when the request gives them. Output: outlines and masses that overlap over siteBuild.massOverlapMm, 1 mm, on the whole site. Two outlines that share an edge do not overlap. Q505. Test: dotnet/SiteAdaptation.Tests/SiteBuild/SiteBuildTests.cs, class R646_OverlapTests.
- **R647 Toposolid cut per neighbourhood.** Input: the plot outlines of each neighbourhood, floors.roadTopography.marginM and limitMm, the optional road edge points. Output: the toposolid cut to the boundary of each neighbourhood, its plot outlines joined and grown by marginM, never to a hull. The plan gives the area of the cut and of the hull it replaces. A road edge point further than limitMm from the cut is listed. Q473, Q502. Test: dotnet/SiteAdaptation.Tests/SiteBuild/SiteBuildTests.cs, class R647_CutTests.
- **R648 Floors placed with another outline.** Input: the floors the tool placed earlier, placedFloors, the plot outlines, designValues.samePoint.sameMm. Output: the floors whose outline differs from the plot now, the same corner points within sameMm, so button 5 replaces them and does not stop on them. Q439, Q503. Test: dotnet/SiteAdaptation.Tests/SiteBuild/SiteBuildTests.cs, class R648_FloorsToReplaceTests.
