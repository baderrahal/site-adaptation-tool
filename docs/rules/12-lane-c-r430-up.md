## Lane C rules, the windows New project, What the tool read and the step gates

Lane C NEWPROJ-UI (PR 112, 31 Oct 2026) and SCAN-UI (1 Nov 2026). The ids R430 to R449 are Lane C's. The design is docs/design/18-new-project.md, the boards are in docs/design/boards. Every rule here sets what a window shows or saves, none sets a value of the plan.

- **R430 Five setup rows of New project.** Input: none, the rows are fixed. Output: the rows site, plot list, villa levels, road levels and parameter sheet, each with the inputs of the settings JSON it fills (baseplan, sales, none, roadSurface as an optional folder, parameterSheet), the buttons it serves and its template. Common/Settings/SetupRows.cs. Tests: R430_SetupTests.cs.
- **R431 Read only setup check.** Input: the settings of the project and a test of whether a path is on disk. Output: per row found, missing or later, whether config is named and on disk, the stops of the buttons and Ready, nothing written. Common/Settings/SetupCheck.cs. Tests: R430_SetupTests.cs.
- **R432 Save setup in R367 format.** Input: the draft of the window, the saved project chosen and the path picked per input. Output: the settings of R367 with the draft laid over them, read back through SettingsJson, the dry run tick and a held parameter sheet kept, the settings given unchanged, nothing written to a model. Common/Settings/SetupSave.cs. Tests: R430_SetupTests.cs.
- **R433 Template workbook of a row.** Input: the row and config. Output: the sheets of the template, the parameter sheet with its columns or the data book sheets by addin.workbookRoles, written as a new xlsx, never into an input folder and never over a file. Common/Settings/TemplateBook.cs. Tests: R433_TemplateBookTests.cs.
- **R434 Saved projects of the work root.** Input: the work root. Output: the folder Saved projects under it and the saved projects in it by name, a file that does not read left out and listed. Common/Settings/SavedStarts.cs. Tests: R430_SetupTests.cs.
- **R435 Scan value status.** Input: the text of scan.json (R427) and the saved scanPicks and conflictPicks of the settings. Output: one row for each of plot outline, plot number, villa block and villa type that has a row of its kind, its sources in file order, the proposed source (the row whose proposedUse is neither empty nor check), the selected source (the saved pick when it names a source of the row, else the proposed), Covers, Checks and the Status, Clear when a source is selected, else Pick with a line on what the best source covers. One row for each file of inputs with what it found, Read or Not read when a check notRead names it. One row for each conflict with its two choices, the selected one (the saved pick when it is sourceA or sourceB, else sourceA) and Open when no pick is saved. NeedsWindow is true when a value is Pick or a conflict is Open. Common/Scan/ScanView.cs. Tests: R435_ScanViewTests.cs, ScanResultsTests.cs.
- **R436 Save scan picks with setup.** Input: the picks of the window and the settings. Output: the settings with the picks laid over scanPicks and conflictPicks, the settings given unchanged, read back through SettingsJson, so they are saved with the setup in the settings JSON of R367, whose formatVersion stays 1 with the new fields null in an older file (Q288). Export writes the sheets Values, Files and Conflicts as the window shows them to a new xlsx and refuses a path that exists. Nothing is written to a model. Common/Scan/ScanPicks.cs. Tests: R435_ScanViewTests.cs.
- **R441 Current files gate.** Input: the settings of the project and the rules profiles in the folder of the rules file, else in rules beside the folder of config. Output: one row per file of the setup but the prototypes folder with its tick Current, the site drawing marked, the profiles by the name each gives itself, Apply of 1 Set up site grey until the site drawing is ticked, the ticks and the rules file laid into the settings on Apply only, and the line "Current files: <files>" after the lines of button 9. A stand-in window that gives no ticks keeps the ticks the settings hold. Common/SetUp/CurrentFiles.cs, CurrentFilesDialog called by SetUpSiteBody, WithReportLine called by ReportBody. Tests: R441_CurrentFilesTests.cs, SetUpSiteTests.cs.
