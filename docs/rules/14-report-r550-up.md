# Report layout, R550 up

Round REPORT-3NOV-B, Bader's change of 3 Nov 2026 to the report Excel of button 9. It goes over the sheet list and top line of docs/addin-mock.md item 6 and docs/design/07-mock.md 7.6.

- **R550 Report file name by ISO.** Input: addin.report.fileName of config, ReportFields of the project settings over it. Output: `<project>-<originator>-<volume>-<level>-<type>-<role>-<number>.xlsx`, the pattern of the past job schedule, `<nbh>` in the volume replaced by the Neighbourhood_ID. A config with no block keeps `<nbh>_Report.xlsx`. A missing field, a name that is no file name or one name for two neighbourhoods stops the button by name. Test: R550_ReportLayoutTests.
- **R551 Report sheets in BIM order.** Input: the sheets of the report. Output: Cover, Plot schedule, Floors, Walls, Issues, Overrides, Rules used, then Summary, Placed, Skipped, Assumed, Accepted warnings, Settings. Cover holds project, NBH, revision, status code, date, tool version, model name and file name. Update from report still reads Placed and Settings (R402) and passes over wall rows. Test: ReportExcelTests.
- **R552 Plot schedule, one row per plot.** Input: the plan as written, plots.csv and the element ids the model holds at report time. Output: the nine columns of the past job schedule in its order, with a row for a plot the plan could not write, then the old plot number from the column addin.report.oldPlotColumn, prototype, mirror, rotation, the levels of the four ramp corners and the ids of the villa, floors, ramp and every wall on the plot's boundary, also one tagged under the plot beside it. El @ Entry is the door level (R408). Floors and Walls list each floor and wall with its id. Test: ReportExcelTests, python/report_excel_check.py.
- **R553 Lists freeze and filter.** Input: a sheet of one table, not Cover or Summary. Output: row 1 frozen, a filter over every column, units in the header. Plot numbers of Plot schedule, Floors, Walls, Issues and Overrides are numbers, a number with a letter or a leading zero stays text, Placed keeps text as the key of R402. Test: python/report_excel_check.py.
- **R554 Run facts for the report.** Input: the model path, the fields of R550, the last run of each step as the pane reads it, the timing files of buttons 1 to 8 and the level Excel of the last run of 6. Output: report_facts_<run id>_<nbh>.json, the input reportFacts of the worker. It fills the top line, the Summary rows of steps 1 and 3 and the Issues column with the count the pane shows (issues plus warnings), and Levels of the box Counts agree, read from the sheet Levels of that Excel. Run time is the last committed run of each button without the waits on a person. Test: R381_ReportRunTests, ReportExcelTests.
- **R555 Changed rules are marked.** Input: changed_rules.json beside the rules file, written by the rules window of Lane C, its list changed with id, name, manual, project and unit. Output: Rules used gains the column Changed and one row per changed rule with its id, name and the two values. No file or an empty list keeps the five columns. Test: R550_ReportLayoutTests.
- **R556 Buttons job from no template.** Input: noTemplate true in a test host spec of buttons with no key copy. Output: the job makes its new project with UnitSystem.Imperial in place of the template, and says so in its open step. Test only, the add-in does not read it. Test: R556_a_job_says_no_template_and_stays_on_the_template_when_silent.
- **R557 A unit plot without official number.** Input: a row of the plot table. Output: its unit number, the official number, else the location plan number when it has a new code of the location plan and one number. No new code, no number or two numbers give no unit (Q355). So all 7 NBHs of the project are offered and build, not 012 and 013 alone. ReadDataRun.UnitNumber called by ScopePlots and DrawingFacts. Tests: R557 in R375_ReadDataTests.cs.
- **R558 Help box stays on screen.** Input: the host of the i, the pane or New project, the place of the i, the height of the box and the work area of its screen. Output: the box stands left of the host, else right of it, else at the work area edge, its top follows the i until the box would pass the bottom of the work area, and it is never taller than the work area, so Close stays in reach and long text scrolls. HelpPlace.Of called by HelpBox.Show. Tests: R558 in R540_HelpBookTests.cs.
