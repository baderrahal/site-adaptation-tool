## Round FIX-1NOV-D rules of Lane D, the shared parameters from one Excel

Bader's task 4 of 1 Nov 2026: the shared parameters are only those the past job links hold, with their names and GUIDs, in one Excel that button 1 reads and binds, each button filling the ones it owns, and a new project edits only that Excel. R461 replaces the parameter list of config, addin.sharedParameters and addin.fixedParameters.

- **R460 Key parameter read details.** Input: a read job of the test host on a copy of an answer key, the step sharedParameters (ParameterSteps of the test host, SharedParameterFile of Common). Output: testhost_<code>_parameters.json as R353 writes it, and per bound definition its spec and group, each as the ForgeTypeId and the label Revit shows, and per category and name on elements how many hold a value and the first value met. Tests: SharedParameterFileTests.cs. The read KC2 of round D2 gives the group Text and the spec String for the 10 link parameters of the IMC key, after R466.
- **R461 One parameter sheet source.** Input: config/shared_parameters.xlsx that addin.parameterSheet of config names, relative to the repo root, or the sheet chosen in Set up site, sheet Parameters, the columns Parameter, GUID, Data type, Group, Category, Filled by, Sample value and Keep in any order and case. Output: the kept parameters in sheet order, each with its name, GUID, data type, group, categories and button, and the names of the rows of Keep No, which are left out. Keep is Yes or No and Filled by a button from 1 to 9 or none, any other is refused, as is a name twice and a GUID of no GUID shape. Sample value is never read. Button 1, button 7, the new project check and key_parameters.py read it, Get template of New project writes its columns. Tests: SetUpSiteLogicTests.cs, R412_NewProjectCheckTests.cs, test_r461_parameter_sheet.py, test_key_parameters.py, test_r412_new_project_check.py.
- **R462 Parameter sheet read inside Revit.** Input: the xlsx file of R461, opened read only and shared. Output: the rows of sheet Parameters as texts, shared and inline strings, numbers and booleans as stored, a row of no value left out, by ParameterBook of Common, so no OpenXml is loaded in Revit (R350). A sheet name the workbook lacks or a file of no xlsx is refused with the reason. Tests: R462_ParameterBookTests.cs, held to XlsxSheet of the worker.
- **R463 Key GUIDs held to the sheet.** Input: the parameter files of R353 of the keys and the parameter sheet of config. Output: python/key_parameters.py writes nothing and prints each name the keys give a GUID that the sheet lacks or gives another, ending 1 when one does, 2 when the sheet does not read. Tests: test_key_parameters.py.
- **R464 Bind by sheet group.** Input: the kept rows of R461. Output: button 1 writes each with its GUID and data type into the shared parameter file of the run and binds it as an instance parameter on its categories under the Revit parameter group whose label is its Group, a row with no group a stop of the planner, a label Revit lacks a stop of the bind. Tests: SetUpSiteLogicTests.cs, the label match is Revit side and not tested.
- **R465 Each button fills its own.** Input: the Filled by of each kept row. Output: button 7 writes on each villa only the plan parameters whose row it fills, the others never and with no issue, floors.plotParameter must be filled by 5 Floors or button 1 stops, and a sheet that gives RRE_ZZ_SP_Prototype-FFL a button is refused, it is never written.
