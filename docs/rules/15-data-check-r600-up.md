## Round R1 rules of build-1, stage 1 Project data from the raw files of a folder

Bader's order of the round: stage 1 runs on a folder as a team hands it over, with no past file, no schedule of a past job and no name given. The worker command dataCheck builds on the scanner of R420 to R427 and reads no rules profile, every value it needs is in the dataCheck block of config/project.json, each CHOSEN by Code with its why beside it. A value the block lacks is a plain line in the data check, never a default of the code. Files: dotnet/SiteAdaptation.Common/DataCheck/, dotnet/CadReader/DataCheckCommand.cs.


- **R600 Data check command.** Input: a request of the command dataCheck with the role scanFolder, a folder, the role config and an output folder, each with an empty SHA-256 allowed for these two roles of this command alone. The folder is walked in ordinal order, no link or junction followed, and each drawing, workbook, PDF file, surface file, rule set file, shared parameter file and the names of the prototype files are found. Output: data_check.json with one row of mark and one plain line for each of the 11 needs, project_profile.json and plots.json in the output folder, and every file the command opened in answer.opened with its name, size, write time and SHA-256 before and after, a change ending the run with exit 4. Another command and another role still refuse an empty SHA-256. Test: R600_DataCheckTests.cs, tests/acceptance/test_r1_stage1.py.
- **R601 Groups by distance.** Input: the outlines of the plots of the plot drawing and dataCheck.groupGapsM, one distance in metres for each group level, the largest group first, turned into the unit the drawing states. Output: for each level the groups of plots whose outlines lie within the distance of each other, a chain of such plots one group, no name of a layer, text or block used. A drawing unit the table does not hold gives no group and a plain line saying so. Test: R600_DataCheckTests.cs, test_groups_are_found_by_shape.
- **R602 Plots with no past file.** Input: the proposed plot outlines, number layer, villa block layer and villa type source of the scan, and the prototype file names read to a code by dataCheck.prototypeFilePattern. Output: for each plot its number, the villa type of the lead source, the mirror of the villa block insert inside it and its groups, each value with a source tag computed or missing, and a reason for each value missing. A block is placed on the plot that holds the centre of what it draws, its insert point only when it draws nothing. A plot with inserts of both hands has no mirror. The villa type of a plot is the one code the first kind of source that gives it agrees on, blocks, texts, a sheet column, a PDF page, a plot with two codes in one kind has none, and a plot whose code another kind contradicts is counted as disputed with the reason in plots.json, the need is weak when more than 1 less strongShare of the typed plots are disputed. No schedule, plots.csv, labels.csv, border, override list or key is read (steps/truth-audit.md items 1, 2 and 7). Test: R600_DataCheckTests.cs, test_plots_are_read_with_no_past_file.
- **R603 Group level words.** Input: the group levels of R601, the texts of the plot drawing outside every plot and within dataCheck.wordReachM of one, and the headers of every sheet that joins to the plots by number. Output: the project's own word for a level when texts of two or more words share their words before the last one for dataCheck.wordShare of the groups of the level, each group with a last word of its own, or when a header names a column whose values part the plots as the groups of the level do. A level with neither has word null and source missing, never a guess. Test: R600_DataCheckTests.cs, test_the_profile_takes_the_projects_own_words.
- **R604 Road edge layer.** Input: the lines of each layer of the plot drawing that is no plot outline layer, with at least dataCheck.roadMinSegments lines, most of them outside the plots, and dataCheck.roadReachM. Output: the layer with a line within the reach of the most plots, and the share of the plots it reaches. Test: R600_DataCheckTests.cs, R604_road_edges.
- **R605 Marks and plain lines.** Input: the counts of R600 to R604 and dataCheck.strongShare and usableShare. Output: for each need the mark strong, usable, weak or missing and one line in CAD and Revit words, at most 160 characters, with no bracket, no code word and no name of a layer that looks like code. Land XML surface files give road levels usable, a coordinate system stated in one gives coordinates usable, rule set and shared parameter files given usable, nothing found missing. Test: R600_DataCheckTests.cs, test_every_need_has_a_mark_and_one_plain_line.
- **R606 Files that fail.** Input: a file that fails to read or is refused by the memory check. Output: a row in data_check.json files with its exact error, the run carries on with the other files and ends with exit 0, an empty folder gives every need missing with a line, and the check never swaps in a dummy file. Test: R600_DataCheckTests.cs, test_a_broken_drawing_is_said_and_the_run_carries_on.
- **R607 Scenario scoring.** Input: the five scenario folders under the work root and the right answer of each, the manifest of each folder before and after. Output: scripts/scenarios/run_stage1.py runs stage 1 on each folder in place, scripts/scenarios/score_scenarios.py writes steps/scenarios.md with counts of plots, numbers, villa types and mirrors right, the marks and the data check lines with file names taken out, and the check that the copies are unchanged. Test: tests/acceptance/test_r1_stage1.py, test_the_scenarios_table_holds_all_five.
- **R608 Clean folder build.** Input: samples/new-project, the made up project of tests/acceptance/made_up_project.py, and build.json naming scripts/scenarios/clean_stage1.py. Output: the build reads the sample and runs stage 1 on it through the worker, it fails when the worker opened a path of scripts/checks/past_paths.txt, read no plot or changed a file of the sample. Test: scripts/checks/clean_folder.py, test_the_clean_folder_check_runs_on_the_sample.
