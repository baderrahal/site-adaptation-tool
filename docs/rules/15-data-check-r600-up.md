## Round R1 rules of build-1, stage 1 Project data from the raw files of a folder

Bader's order of the round: stage 1 runs on a folder as a team hands it over, with no past file, no schedule of a past job and no name given. The worker command dataCheck builds on the scanner of R420 to R427 and reads no rules profile, every value it needs is in the dataCheck block of config/project.json with its why beside it. A value copied from the past job says so there and is no choice of this command. A value the block lacks is a plain line in the data check, never a default of the code. Files: dotnet/SiteAdaptation.Common/DataCheck/, dotnet/CadReader/DataCheckCommand.cs.

- **R600 Data check command.** Input: a request of the command dataCheck with the role scanFolder, a folder, the role config and an output folder, each with an empty SHA-256 allowed for these two roles of this command alone. The folder is walked in ordinal order, no link or junction followed, and each drawing, workbook, PDF file, surface file, rule set file, shared parameter file and the names of the prototype files are found. Output: data_check.json with one row of mark and one plain line for each of the 11 needs, a value for the mirror, the files read or not read and the ties, project_profile.json and plots.json in the output folder, and every file the command opened in answer.opened with its name, size, write time and SHA-256 before and after, a change ending the run with exit 4. Another command and another role still refuse an empty SHA-256. Test: R600_DataCheckTests.cs, tests/acceptance/test_r1_stage1.py.
- **R601 Groups by distance.** Input: the outlines of the plots of the plot drawing and dataCheck.groupGapsM, one distance in metres for each group level, the largest group first, turned into the unit the drawing states. Output: for each level the groups of plots whose outlines lie within the distance of each other, a chain of such plots one group, no name of a layer, text or block used. A drawing that states no unit is taken as metres and says so, and the groups are then weak. A unit the table does not hold gives no group at all, the plots carry an empty list of groups and the reason. An outline with no number that lies inside no plot and is no larger than dataCheck.standInMaxArea times the median plot gets no row and stays in the distance test, so the gap of a plot with no number reads as no road. Two candidate outlines that tie on the plots they cover, one the other with more layers, are broken to the one with the fewest layers and the tie is said under ties. Any other tie leaves no proposal and the line names it. Test: R600_DataCheckTests.cs, test_groups_are_found_by_shape.
- **R602 Plots with no past file.** Input: the proposed plot outlines, number layer, villa block layer and villa type source of the scan, and the prototype file names read to a code by dataCheck.prototypeFilePattern. Output: for each plot its number, the villa type, the mirror of the villa block inside it and its groups, each value with a source tag computed or missing, and a reason for each value missing. A block is placed on the plot that holds the centre of what it draws and belongs to the smallest outline that holds it. The villa type of a plot is the one code the first kind of source that gives it agrees on, blocks, texts, a sheet column, a PDF page. A plot another kind of source contradicts is counted as disputed with the reason in plots.json, and the need is weak when more than 1 less strongShare of the typed plots are disputed or when a sheet holds villa type codes for many plots and joins few of them. A plot with a label of two numbers is written with number null, source missing and the reason naming both numbers, never the last, and the sheet and page sources, which join by number, are not used for it. Every line of a need follows the drawing the scan chose to give the plots, never the first drawing that has a proposal. A plot with a hole is flagged and what lies in the hole is left out of its mirror. The mirror is the sign of the block scale, a weak value on every plot because the folder does not say which hand a prototype file has. No schedule, plots.csv, labels.csv, border, override list or key is read (steps/truth-audit.md items 1, 2 and 7). Test: R600_DataCheckTests.cs, test_plots_are_read_with_no_past_file.
- **R603 Group level words.** Input: the group levels of R601, the texts of the plot drawing outside every plot and within dataCheck.wordReachM of one, and the headers of every sheet that joins to the plots by number. Output: the project's own word for a level. A header whose values part the plots as the groups do is enough alone. A word of the drawing alone needs dataCheck.wordMinGroups groups and a share of dataCheck.wordShare of the groups of the level. Two words that both qualify, or two headers, leave the level with word null, source missing, the candidates and the reason named in project_profile.json and in the line. A level with none has word null and source missing, never a guess. Test: R600_DataCheckTests.cs, test_the_profile_takes_the_projects_own_words.
- **R604 Road edge layer.** Input: the lines of each layer of the plot drawing that is no plot outline layer, with at least dataCheck.roadMinSegments lines, dataCheck.roadOutsideShare of them outside the plots, and dataCheck.roadReachM. Output: the layer with a line within the reach of the most plots and the share of the plots it reaches. Reach alone proves no road, so the mark is at most usable and the line says not scored. Test: R600_DataCheckTests.cs, R604_road_edges.
- **R605 Marks and plain lines.** Input: the counts of R600 to R604 and dataCheck.strongShare and usableShare. Output: for each need the mark strong, usable, weak or missing and one line in CAD and Revit words, at most 160 characters, with no bracket, no code word and no name of a layer that looks like code. A mark never rises as the data gets worse, a need takes the worst mark its facts give. Outlines with no number or two numbers, numbers outside every outline and a number used twice are said in counts, a share never passes 100 percent and a repeated number makes the plot numbers weak. Land XML surface files give road levels usable, a coordinate system stated in one gives coordinates usable, rule set and shared parameter files given usable, nothing found missing. Test: R600_DataCheckTests.cs, test_every_need_has_a_mark_and_one_plain_line.
- **R606 Files that fail.** Input: a file that fails to read, is held open by another program or is refused by the memory check, which holds a drawing to its size times the number of its file type in dataCheck.drawingPeak, dwg or dxf, and the floor siteBuild.minFreeGB. Output: a row in data_check.json files with its exact error, the run carries on with the other files and ends with exit 0, an empty folder gives every need missing with a line, and the check never swaps in a dummy file. Test: R600_DataCheckTests.cs, test_a_broken_drawing_is_said_and_the_run_carries_on.
- **R607 Scenario scoring.** Input: the five scenario folders under the work root and the right answer of each, the manifest of each folder before and after, and built_from.json in each run folder with the commit of the worker. Output: scripts/scenarios/run_stage1.py runs stage 1 on each folder in place, scripts/scenarios/score_scenarios.py writes steps/scenarios.md with counts and marks only, scripts/scenarios/second_check.py counts the plots of the sheet by neighbourhood and villa type by another route and shows the under read and over read. Test: R600_DataCheckTests.cs, R607_the_scores_table, tests/acceptance/test_r1_stage1.py.
- **R608 Clean folder build.** Input: samples/new-project, the made up project of tests/acceptance/made_up_project.py, and build.json naming scripts/scenarios/clean_stage1.py. Output: the build reads the sample and runs stage 1 on it through the worker, it fails when the worker opened a path of scripts/checks/past_paths.txt, read no plot or changed a file of the sample. Test: R600_DataCheckTests.cs, R608_the_sample_project, scripts/checks/clean_folder.py.

## Round R2 C1 rules of build-1, the gaps of stage 1 that block a correct build

Bader's order of the round: the villa type code map, the hand of each prototype and the group words are project inputs, found by what the handed over files hold and confirmed by a person, never copied from a past file. Nothing here reads a sheet or column by its name.

- **R630 Code table.** Input: every sheet of the workbooks of the folder that lists no plots, the prototype codes, dataCheck.codePattern, dataCheck.codeTableMaxPairs, strongShare and usableShare. Output: in project_profile.json codeMap.proposed, each row old, new and source computed, codeMap.foundIn and every other table under candidates. A table is two columns side by side whose cells both have the shape of a code, at least two pairs, one that renames, a pair repeated on under 1 less strongShare of its rows, at most codeTableMaxPairs pairs and one side holding usableShare of the prototype codes. A row with one code is skipped, and a first row that holds codes counts as a row. The side whose base codes the drawings use more is the old one, a tie is read left to right, by no word of a header. Best first by prototype codes covered, renames, pairs, then the order of the files. No prototype codes or no such table gives an empty list, source missing and a line that says it. A proposal changes no plot. Test: R630_StageOneGapsTests.cs, test_a_table_of_old_to_new_codes_is_found_by_what_it_holds, test_no_table_says_so_and_lets_the_user_type_it.
- **R631 Typology column.** Input: the columns of each sheet that lists usableShare of the plots by number, and the groups of R601. Output: typologyColumn.proposed with workbook, sheet, column, plots and prototypePlots, null when there is none, and the rest under candidates. A column qualifies when a cell of code shape is given for usableShare of the plots, it holds at most codeTableMaxPairs codes, strongShare of its coded plots hold a code found in two groups or more of the finest level, as a type runs across groups and a block name does not, and under strongShare of them repeat the code the drawing gives, as a copy of the drawing settles nothing. Best first by plots whose whole cell is a prototype code, then the share of the rows of the column so filled, then the later column. Test: R630_StageOneGapsTests.cs, test_a_typology_column_per_plot_is_proposed.
- **R632 What a person confirmed.** Input: the optional role projectProfile, a file with codeMap, hands, levels and typologyColumn, which may carry an empty SHA-256 for dataCheck alone. Output: a value of the wrong shape or an unreadable file refuses the run with its reason, so a run that goes on honoured all of it. A confirmed column gives each plot its code, a plot it does not list or lists with no code has none and says why, what the drawing said is not kept for it, a plot whose label holds two numbers keeps what the drawing gives, and a column that does not join is said in files with no plot changed. The confirmed map then turns the code once: a code that is also a new code stands, one old code with two new codes is no pick and is weak with both named, and an old code no prototype holds is looked for in the drawing and the sheets too. Each confirmed block carries source person entered and each plot value worked out from it computed, the code as read stays in codeRead. A plot typed with no prototype file makes the need at most usable. Test: R630_StageOneGapsTests.cs, test_a_confirmed_map_gives_the_new_code_with_its_source, test_a_proposed_map_changes_no_plot_until_it_is_confirmed.
- **R633 Prototype hand and mirror.** Input: the inserts of the villa block layers inside the plots, the code each block name holds, dataCheck.handGuessShare, and the confirmed hands. Output: hands.proposed for each prototype code, right when its blocks are drawn unmirrored on handGuessShare of the plots that hold one, left when mirrored, null otherwise or with no block, with hands.evidence and hands.proposedAs saying it is a guess, no prototype file being opened. The mirror of a plot is the sign of the block scale, turned over when the confirmed hand of its code is left. It stays weak with no confirmed hand, and with one when the block in the plot is not of the plot's own type. A guess changes no mirror until it is confirmed. Test: R630_StageOneGapsTests.cs, test_mirror_follows_the_block_scale_and_the_confirmed_hand, test_a_hand_is_proposed_per_prototype_and_shown_as_a_guess.
- **R634 Words only from a text that names groups.** Input: the texts and headers of R603, dataCheck.groupNamePattern and wordShare, and the confirmed levels. Output: a text counts for a word only when its last token matches groupNamePattern, as a group name does and the last word of a note or a building does not. A header counts only when its values name two groups or more and wordShare of the groups of the level, so one value over one big group and a lone plot names nothing. With none the level has word null, source missing and the line asks to name it once, a level the person named takes that word with source person entered. Test: R630_StageOneGapsTests.cs, test_a_group_word_comes_only_from_a_text_that_names_groups, test_a_level_the_user_names_is_taken_with_its_source.
- **R635 Scoring before and after a confirmed profile.** Input: the runs of R607, then each scenario again by run_stage1.py --confirmed into runs/<name>_confirmed on what its own first run proposed, by scripts/scenarios/confirmed_profile.py, the codes, column, guesses and words of the tool and nothing from a past file or an answer. Output: steps/scenarios.md holds both tables with counts and marks only, each run tied to its commit by built_from.json and its folder by the manifest. second_check.py --confirmed counts the villa types per neighbourhood from the sheet by openpyxl against plots.json. Test: scripts/checks/test_scenarios.py, test_the_scenarios_table_shows_c1_scored_on_all_five.
