
## Round REC rules

- **R400 Record sizes.** The files a session reads at start stay small, and no record grows past what a session reads by grep. CLAUDE.md is at most 10 KB. steps/PROGRESS.md is at most 60 lines and 6 KB, with no line over 200 characters. The top entry of steps/log.md, from its ## heading to the next, is at most 4 KB. No file of docs/ or steps/ outside steps/history/ is over 100 KB. A KB is 1,024 bytes. A record that would pass its cap is cut into parts at line ends with no byte changed, as Round REC cut docs/rules.md into docs/rules/, docs/addin-design.md into docs/design/ and the round file of Round ADDIN 0a to 4e into steps/history/round-addin/. python/record_parts.py joins the parts in name order for a reader that needs the whole, and names every file over its cap. docs/rules/index.md, written by python/rules_index.py, lists each rule id with its bold title under its part. python/split_proof.py and steps/runs/rec/second_route.sh prove a cut by the SHA-256 of the original and of its parts joined. test_r400_record_sizes holds the caps in the gate.
- **R401 The status of each plotted value.** python/rule_status.py, moved from steps/investigations/rule-status-scripts/audit.py of Round AUDIT-RULES, which still runs it, gives each value of the rules profile and of config/project.json, kinds value and host, one of six statuses from the records only. CHOSEN by Bader is a closed answer of Bader near the value, a question that named the value and that Bader has closed, or a Bader line of CLAUDE.md. The questions the audit asked of itself, Q100 to Q104, are no evidence, every other question of Bader's turn is open. MEASURED is a keyRules entry or hand rule with its share, strong or weak at the strong share of the Majority rule, and a field of a level profile outside keyRules tied to the keyRules entry of the same profile that measures the same decision. DOCUMENT is a value under a source outside the level profiles, a client document, named by that source with the page, appendix, section or sheet where the records write one after the revision of that document, else UNKNOWN. RECOMMENDED is an open question that names the value, CHOSEN by Code the word CHOSEN by it, and UNKNOWN the rest, with the nearest source above the value when there is one. With --write it puts them in the block status, the last key of the rules profile, one entry per value by file and dotted path, the status first and then the fields that status needs, the rest of the file byte for byte, and refuses a write that would change a value. The block is never read as a value or as evidence, so a second write gives the same bytes, and --check lists the entries whose evidence changed since the last write. Bader reviews the values CHOSEN by Code and the UNKNOWN values that set the position or a level of a plot from steps/investigations/status-review.md. The plan part, the status beside each sourced value of a plot and its count by field and status in the summary of step 15, comes in Round ADDIN 4g1 PR 4.
