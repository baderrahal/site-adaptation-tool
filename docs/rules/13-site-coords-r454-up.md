## Lane B rules, the coordinate system and site position of button 1 from CAD

Lane B FIX-1NOV-B task 3 (1 Nov 2026). The ids R454 to R456 are of this task. Every value is a key of the block coordinates of config/project.json, the Revit run of the CAD source waits for the runner (Q328).

- **R454 Coordinate system of the inputs.** Input: each drawing and LandXML of the pane, the baseplan, the footprint, the Road Layout and each LandXML of the road surface folder, read by the worker command crs with the SHA-256 of each held over the read, and coordinates.systems and coordinates.expectedEpsg. Output: crs.json with the name of the system each drawing states in the GeoData of its model space and the epsgCode each LandXML states, then Agree when every stated system maps to one EPSG code, Conflict when two differ, NoneStated when none states one, one plain line per input in the Set up site window. A conflict, a code unlike coordinates.expectedEpsg or a name coordinates.systems does not map stops button 1. A file that states no system is listed and does not stop (Q325). CadReader/CoordinateSystemRead.cs Command, OfDrawing, NameOfDefinition and OfLandXml, registered in CadReader/WorkerReads.cs. Common/SetUp/CoordinateSystems.cs CoordinateSettings.From and CoordinateSystems.Agree, called by SiteFromCad.Load. Common/SetUp/SitePosition.cs CoordinateRequest.Make and Run, called by AddIn/Commands/SetUpSiteBody.cs. Tests: R454_SiteCoordinatesTests.cs.
- **R455 Site position from CAD.** Input: the plot outlines of the baseplan read by crs, the EPSG code of R454 and coordinates.originRoundM, angleToTrueNorthDeg, originElevationM, positionName and placeName. Output: the shared origin at the centre of the box of every plot outline rounded to originRoundM (Q326), the internal origin at it with shared height 0, the survey point and the project base point on the internal origin at originElevationM, internal and shared, the relation of the past position file (Q327), true north angleToTrueNorthDeg, the latitude and longitude of the origin by UtmMath on WGS 84, and the named position positionName made active with the site location set before SetProjectPosition. coordinates.source positionFile keeps the position file of addin.position, the levels and units come from it under both sources (Q328). Common/UtmMath.cs ZoneOf and ToLatLon, Common/SetUp/SitePosition.cs SiteFromCad.FromCad and Load called by SetUpRun.Preview, SetUpTarget.From taking the CAD site, SetUpPlanner.Changes and ReadBack holding the location, AddIn/Revit/RevitSiteDocument.cs SetLocation, SetNamedPosition and SetSiteLocation called by SetUpRun.Apply. Tests: R454_SiteCoordinatesTests.cs, SetUpSiteLogicTests.cs.
- **R456 Three CAD control points.** Input: the plot outlines of the baseplan read, coordinates.controlPointCount and controlPointLimitMm, the position of R455 and the shared point Revit gives for an internal point, by the transform of the position in a dry run and by ProjectLocation after Apply. Output: the south west corner, the least east plus north, then each next corner the one whose nearest chosen corner is the farthest, a tie to the least north, the least east, then the plot name (Q329), each a row of the check points of the Set up site view with its CAD and Revit shared point and the gap in mm, passing at controlPointLimitMm. Common/SetUp/ControlPoints.cs Pick called by SiteFromCad.Load and Check called by SetUpPlanner.CheckPoints. Tests: R454_SiteCoordinatesTests.cs, SetUpSiteLogicTests.cs.
