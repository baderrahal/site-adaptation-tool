- **R454 Coordinate system of the inputs.** Input: each drawing and LandXML of the pane, the baseplan, the footprint, the Road Layout and each LandXML of the road surface folder, read by the worker command crs with the SHA-256 of each held over the read, and coordinates.systems and coordinates.expectedEpsg. Output: crs.json with the name of the system each drawing states in the GeoData of its model space and the epsgCode each LandXML states, then Agree when every stated system maps to one EPSG code, Conflict when two differ, NoneStated when none states one, one plain line per input in the Set up site window. A conflict, a code unlike coordinates.expectedEpsg or a name coordinates.systems does not map stops button 1. A file that states no system is listed and does not stop (Q325). - **R456 Three CAD control points.** Input: the plot outlines of the baseplan read, coordinates.controlPointCount and controlPointLimitMm, the position of R455 and the shared point Revit gives for an internal point, by the transform of the position in a dry run and by ProjectLocation after Apply. Output: the south west corner, the least east plus north, then each next corner the one whose nearest chosen corner is the farthest, a tie to the least north, the least east, then the plot name (Q329), each a row of the check points of the Set up site view with its CAD and Revit shared point and the gap in mm, passing at controlPointLimitMm.
