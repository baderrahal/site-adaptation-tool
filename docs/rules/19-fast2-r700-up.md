## FAST-2 of build-2, the logic for any project, fast build 6 to 8 Nov

Bader's order of 6 Nov. Written by build-2 for steps/tasks/FAST-2-build-2.md, ids R700 to R719. Each rule is CHOSEN by Code unless its question says otherwise.

- **R700 Shared parameters from the parameter sheet.** Input: the parameter sheet the request of dataCheck names as input role parameterSheet, the sheet of the project settings, guarded by the runner as every input and taken with an empty SHA-256, and the count of Revit shared parameter text files in the folder. Output: the need sharedParameters. Strong when the sheet holds at least one row for the villa links, category RVT Links, and each such row has a GUID. Usable when a link row has no GUID, the names listed, or when no sheet reads but the folder holds a shared parameter text file. Weak when the sheet is there and does not read, with the reason. Missing when the request names no sheet, the line then says only that no parameter sheet was given to the data check, so a folder alone never gets the sheet of the tool, when the sheet is not there, or it holds no link row, each said in plain words. Test: dotnet/SiteAdaptation.Tests/FAST2/R700_SharedParametersNeedTests.cs, R700_ParameterSheetInputTests.cs, python/tests/test_r700_stage1_sheet.py.
- **R701 No free memory floor.** Input: free memory. Output: python/window_lock.py, python/c3d_window.py and python/place_codes.py log free memory and never wait, skip or stop on it, only the lock, the window processes, the time limit and a failed run hold a run back. python/c3d_probe.json holds no minFreeGB. The worker, the listener and siteBuild.minFreeGB of config follow once their tests are on build-2's list, steps/seam.md. Test: python/tests/test_window_lock.py test_r701_*, python/tests/test_data_book.py test_r701_*, python/tests/test_round16.py test_r701_*.
- **R702 No past share, new project.** Input: the config of the report run with the project mode of the request laid over designBasis.mode, and projectRules.pastJobMode. Output: a run whose mode is set and other than the past job mode is a new project. Its report prints no share and no strength measured on the past models: the box Rules applied says not measured on this project in both cells, the Basis of Rules used and Assumed names the rule with no share, and the Issues sheet lists no weak rule. A config that names no past job mode or no mode keeps the shares. python/report_excel_check.py holds the same with its --mode. Test: dotnet/SiteAdaptation.Tests/FAST2/R702_ReportSourcesTests.cs, python/tests/test_r702_report_sources.py.
- **R703 Source column on value sheets.** Input: the plan values of each row of Plot schedule, Floors and Walls, each a value with its source. Output: a column Source before the element ids of each of the three sheets, the sources of the row each once: computed, rule, person entered, default, override, past, missing first in that order, any other tag of the plan after them by name. pastJob reads past, keyRules rule, user pick and confirmed person entered. A plan value with no value and no source is missing, one with a value and no source names nothing. The other sheets name their source already: Issues and Overrides in their column Source, Rules used and Assumed in Basis. Test: dotnet/SiteAdaptation.Tests/FAST2/R702_ReportSourcesTests.cs, python/tests/test_r702_report_sources.py, python/tests/test_report_excel_check.py.
