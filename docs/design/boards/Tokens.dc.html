Rules for Code
1. Colours, fonts, sizes and icons come only from Theme.xaml by key. A test fails on any colour or font size in another file.
2. Layout, labels and order follow these artboards. Nothing smaller than 12.
3. Every section has one help line. Every rule shows its plain name, with its id as a tooltip.
4. A change to the look is a question for Bader, never a choice by Code.
5. Each window gets a Revit screenshot beside its artboard, and every difference is listed.
